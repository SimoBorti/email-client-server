# 📧 Java Email Client-Server

Applicazione desktop **Client-Server** sviluppata in **Java** che permette l'invio di messaggi di testo tramite comunicazione di rete basata su **Socket TCP**. Il progetto include un'interfaccia grafica moderna sviluppata con **JavaFX**.

---

## 🚀 Funzionalità Principali
* **Architettura Client-Server:** Comunicazione di rete basata su socket TCP per lo scambio di messaggi in tempo reale.
* **Interfaccia Grafica (GUI):** Sviluppata in JavaFX per offrire un'esperienza utente pulita e interattiva.
* **Invio di Stringhe:** Protocollo di comunicazione testuale personalizzato per gestire l'invio e la ricezione dei messaggi tra client e server.
* **Gestione della Connessione:** Il server gestisce l'ascolto delle richieste e l'interazione con il client.

---

## 🛠️ Tecnologie Utilizzate
* **Linguaggio:** Java
* **Networking:** Java Sockets (`java.net.ServerSocket`, `java.net.Socket`)
* **Interfaccia Grafica:** JavaFX

---

## 💡 Note di Sviluppo
Il progetto è stato strutturato applicando una netta separazione tra la logica di rete e l'interfaccia grafica, garantendo modularità e pulizia del codice.
